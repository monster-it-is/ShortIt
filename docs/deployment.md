# Deploy ShortIt at $0 (Render + Atlas + GitHub)

Do **not** create accounts, publish the repo, or click Deploy until you explicitly choose to. This file is the exact runbook. Cost limits and rejected paid options are in [zero-cost-hosting.md](./zero-cost-hosting.md).

Target architecture:

| Piece | Service | URL |
| --- | --- | --- |
| Frontend | Render Static Site (free) | `https://shortit-web.onrender.com` (name may differ) |
| Backend | Render Web Service, plan **Free** | `https://shortit-api.onrender.com` |
| Database | MongoDB Atlas **Free (M0)** | SRV URI in `MONGODB_URI` |
| Git | GitHub Free, **public** repo | origin on GitHub |
| CI | GitHub Actions `ubuntu-latest` | `.github/workflows/ci.yml` |
| TLS | Render-managed certificates | HTTPS only, automatic |

No custom domain. No Redis. No Render Postgres. No credit card. No paid add-ons.

## 0. Local checks (already possible)

From a machine with Node 18+ and pnpm 10:

```bash
cd backend
pnpm install
pnpm exec tsc -b
pnpm test
pnpm run build
pnpm start
```

`pnpm start` listens on `HOST` (default `0.0.0.0`) and `PORT` (default `8080`). Render sets `PORT`.

```bash
cd frontend
pnpm install
pnpm exec tsc -b
pnpm run lint
pnpm test
pnpm run build
```

Optional production-like preview (uses `frontend/.env` / `.env.production` for `VITE_API_BASE_URL`):

```bash
cd frontend
pnpm run preview
```

E2E (isolated in-memory Mongo, not Atlas):

```bash
cd e2e
pnpm install
pnpm exec playwright install chromium
pnpm test
```

## 1. GitHub (when you authorize publishing)

1. Create a **GitHub Free** account if needed. **Do not add a credit card.**
2. `git init` in this project if it is not already a repository. Do not commit `.env` files.
3. Create a **public** repository (private Actions minutes are capped and can become billable).
4. Push `main` (or `master`). Confirm `.env` is not in the tree.
5. Actions should run `.github/workflows/ci.yml` on `ubuntu-latest` only. Do not change the runner label to a larger runner.

## 2. MongoDB Atlas M0 (when you authorize a database)

1. Create an Atlas account. **Do not add a payment method.**
2. Create a project. Deploy **one Free cluster** (M0). Provider **AWS**. Region closest to Render Oregon: **Oregon (us-west-2)** when available on M0; otherwise the nearest M0 AWS region.
3. Do **not** select Flex, M10, backups, peering, or private endpoints.
4. Create a **database user** (SCRAM password). Privileges: `readWrite` on database `shortit` only. Not `atlasAdmin`. Use a long random password. URL-encode it in the URI.
5. Skip sample data if you want to conserve the 512 MB cap.
6. Connection string: **Drivers** → Node.js. Use `mongodb+srv://.../shortit?retryWrites=true&w=majority`. Put it only in Render later.

### Network Access (required before the API can connect)

Follow the safer-first order in [zero-cost-hosting.md](./zero-cost-hosting.md#atlas-network-access-and-render-outbound-ips).

After the Render API exists:

1. Open the **shortit-api** service → **Connect** → **Outbound**. Copy every CIDR.
2. Atlas → **Network Access** → **Add IP Address** for each CIDR. Comment them `render-oregon-outbound`.
3. Add **your current IP** if you will connect from a laptop.
4. Wait a few minutes for Atlas to apply the list, then restart the Render API if it failed `serverSelection`.

If the Outbound list is empty (legacy Oregon workspace created before 23 January 2022), create a **new Hobby workspace** and recreate the services there. Do not buy a proxy or dedicated IPs.

Only if CIDR allowlisting cannot work, read the `0.0.0.0/0` consequences in the cost document before using it.

## 3. Render Hobby (when you authorize hosting)

1. Sign up at Render with GitHub. You get a **Hobby** workspace. **Do not add a payment method. Do not upgrade to Pro.**
2. Confirm Billing shows **Hobby**, $0, no card.
3. **New → Blueprint**. Point it at the public GitHub repo and `render.yaml`.
4. Service names in the blueprint: `shortit-api` (Free web service), `shortit-web` (static). Keep **plan: free** on the API.
5. Dashboard prompts (`sync: false`):
   - `MONGODB_URI` — Atlas SRV URI from step 2.
   - `CORS_ORIGIN` — leave a placeholder such as `https://localhost` until the static site URL exists, or fill it in step 6.
   - `VITE_API_BASE_URL` — leave until the API URL exists.
6. `JWT_SECRET` is generated by the blueprint (`generateValue`). Do not replace it with a short string (production minimum is 32 characters).
7. Do **not** attach disks, scale instances, add custom domains, enable dedicated IPs, or create Postgres/Key Value.

Render sets `PORT`. The process binds `0.0.0.0:$PORT`. `TRUST_PROXY=1` matches Render's single reverse-proxy hop so rate limits see client IPs (not `true`, which would trust spoofed `X-Forwarded-For`).

### First-deploy order

1. Let **shortit-api** finish building. Open `https://<shortit-api-host>/api/health` — expect `{"status":"ok"}` (first hit may take ~1 minute if the instance is spinning up).
2. Copy that origin. On **shortit-web**, set `VITE_API_BASE_URL=https://<shortit-api-host>/api` (no trailing slash on the origin).
3. Manual **Deploy** of **shortit-web** so Vite bakes the API URL into the bundle. `VITE_*` is **build-time only**.
4. Copy the static site origin, e.g. `https://<shortit-web-host>`.
5. On **shortit-api**, set `CORS_ORIGIN` to that exact origin, HTTPS, **no trailing slash**. Save — Render restarts the API.
6. Confirm Atlas Network Access includes the API outbound CIDRs.

Do not enable automatic paid upgrades if Render offers them.

## 4. Confirm behaviour

| Check | Expected |
| --- | --- |
| `https://<api>/api/health` | `{"status":"ok"}`; HTTPS; HSTS on the API in production |
| Frontend `/` | Landing loads over HTTPS |
| Hard refresh `/home` while logged out | SPA rewrite serves `index.html`; app redirects to `/` |
| Register / login | JWT in `localStorage` key `shortit_token`; dashboard at `/home` |
| Create `https://example.com` | Card appears; copy uses `https://<web-host>/<slug>` |
| Open `/<slug>` | Resolves via `GET /api/link/resolve/:slug`, increments clicks, redirects |
| Idle ~20 minutes, then open a short URL | About **one minute** delay, then redirect. Not always-on. |
| Browser origin not in `CORS_ORIGIN` | Browser blocks the API; allowlist is not `*` |

## 5. Environment reference

Backend (Render Web Service):

| Variable | Required | Notes |
| --- | --- | --- |
| `PORT` | Injected | Do not override unless you know Render's assigned port |
| `HOST` | `0.0.0.0` | Blueprint sets this |
| `NODE_ENV` | `production` | Enables HSTS and production JWT length / rate limits |
| `MONGODB_URI` | Yes | Atlas SRV; secret |
| `JWT_SECRET` | Yes | ≥32 chars; secret |
| `CORS_ORIGIN` | Yes | Exact frontend origin(s), comma-separated, no `*` |
| `TRUST_PROXY` | `1` | Render hop count |

Frontend (Render Static Site, **build-time**):

| Variable | Required | Notes |
| --- | --- | --- |
| `VITE_API_BASE_URL` | Yes in production | `https://<api-host>/api` |

Templates: `backend/.env.production.example`, `frontend/.env.production.example`.

## 6. What this repo does **not** do

- Create Render/Atlas/GitHub accounts.
- Push to GitHub or trigger a live deploy.
- Open Atlas to `0.0.0.0/0`.
- Keep the API awake with a pinger (that burns the 750-hour cap).
- Store secrets in git or `VITE_*` variables.
